# 루틴 실행기

루틴을 한 번에 한 항목씩 띄우는 단일 HTML 앱이다. 일하는 방식과 구조는 `CLAUDE.md`, 지금 상태는 `docs/STATUS.md` 에 있다.

## 업데이트 기록

### 2026-11-08

- 맥앱의 판 이름을 빌드한 시각(서울)으로 자동으로 만든다. 이름은 `26.11.08 (1247)` 꼴이고, 화면에 보일 때는 앞에 `v` 를 붙인다.
- 맥앱의 빌드 번호는 1970 년부터 지난 분 수로 바꿨다. 예전 번호(`20261108` 꼴)보다 커서 계속 올라간다.
- 웹 화면의 `VERSION`(`YYYY-MM-DD.N`)은 그대로다.
