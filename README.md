# 루틴 실행기

루틴을 한 번에 한 항목씩 띄우는 단일 HTML 앱이다. 일하는 방식과 구조는 `CLAUDE.md`, 지금 상태는 `docs/STATUS.md` 에 있다.

## 업데이트 기록

### 2026-11-08

- 맥앱의 판 이름을 빌드한 시각(서울)으로 자동으로 만든다. 이름은 `26.11.08 (1247)` 꼴이고, 화면에 보일 때는 앞에 `v` 를 붙인다.
- 맥앱의 빌드 번호는 1970 년부터 지난 분 수로 바꿨다. 예전 번호(`20261108` 꼴)보다 커서 계속 올라간다.
- 웹 화면의 `VERSION`(`YYYY-MM-DD.N`)은 그대로다.
- 맥앱에 앱 안 업데이트를 넣었다. 앱을 켤 때 새 판이 있으면 한 번 묻고, 「설치 후 다시 열기」를 눌러야 설치한다. 앱 메뉴의 「업데이트 확인…」으로 언제든 확인할 수 있다.
- 앱 메뉴의 「Routine 정보」 창에 설치된 판(`v26.11.08 (1247)` 꼴)과 「업데이트 확인」·「설치」 버튼이 있다.
- 새 판은 `tools/publish-mac.sh` 로 올린다 (`https://start.comms.ms/apps/routine/version.json`). 받은 파일은 sha256 이 맞을 때만 설치한다.
- 이 기능이 없는 옛 맥앱은 한 번만 손으로 새로 설치해야 한다 (`tools/build-mac-app.sh --install`).
