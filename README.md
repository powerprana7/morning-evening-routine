# 루틴 실행기

루틴을 한 번에 한 항목씩 띄우는 단일 HTML 앱이다. 일하는 방식과 구조는 `CLAUDE.md`, 지금 상태는 `docs/STATUS.md` 에 있다.

## 업데이트 기록

### 2026-11-24

- 루틴 편집 화면의 「전체 복사」 지시문 앞에 머리말을 붙였다. 어느 도구에서 복사했는지, 맥의 저장소 경로, `CLAUDE.md` 부터 읽으라는 안내, 그리고 이 파일의 `ROUTINES` 는 Checks 에 연결하지 않은 기기만 쓰는 기본 목록이라는 경고가 들어간다. (웹 `2026-11-24.1`)

### 2026-11-18

- 시작 화면 아래 단추(소리·알림·루틴 편집·Timeline·Checks)를 「설정 ▾」 뒤에 접어 두었다. 누르면 펼쳐진다. (웹 `2026-11-18.3`)
- 숫자키 1·2·3 으로 루틴이 시작되던 것을 없앴다. 연결 코드 칸에 숫자를 넣을 수 있다. (웹 `2026-11-18.2`)
- 루틴 목록을 Checks 서버에서 받는다. 시작 화면 `✓ Checks` 에 Checks 앱의 6자리 Pairing code 를 넣으면 연결된다. 연결된 기기에서는 편집 화면 버튼이 「Checks 에 저장」이 되고, 저장하면 다른 기기는 앱을 열 때 받는다. 연결 안 한 기기는 전과 같다. (웹 `2026-11-18.1`)

### 2026-11-12

- 이브닝 루틴이 27개에서 28개가 됐다. 「타임테이블을 보고 복기한다」 다음에 「Checks」가 나온다. (웹 `2026-11-12.1`)

### 2026-11-08

- 맥앱의 판 이름을 빌드한 시각(서울)으로 자동으로 만든다. 이름은 `26.11.08 (1247)` 꼴이고, 화면에 보일 때는 앞에 `v` 를 붙인다.
- 맥앱의 빌드 번호는 1970 년부터 지난 분 수로 바꿨다. 예전 번호(`20261108` 꼴)보다 커서 계속 올라간다.
- 웹 화면의 `VERSION`(`YYYY-MM-DD.N`)은 그대로다.
- 맥앱에 앱 안 업데이트를 넣었다. 앱을 켤 때 새 판이 있으면 한 번 묻고, 「설치 후 다시 열기」를 눌러야 설치한다. 앱 메뉴의 「업데이트 확인…」으로 언제든 확인할 수 있다.
- 앱 메뉴의 「Routine 정보」 창에 설치된 판(`v26.11.08 (1247)` 꼴)과 「업데이트 확인」·「설치」 버튼이 있다.
- 새 판은 `tools/publish-mac.sh` 로 올린다 (`https://start.comms.ms/apps/routine/version.json`). 받은 파일은 sha256 이 맞을 때만 설치한다.
- 이 기능이 없는 옛 맥앱은 한 번만 손으로 새로 설치해야 한다 (`tools/build-mac-app.sh --install`).
