## 알려진 함정

- **외부 파일을 `fetch` 로 읽으면 `file://` 에서 통째로 죽는다** — CORS (D-002)
- **`setInterval` 로 시간을 누적하면 백그라운드에서 밀린다** — `Date.now()` 차이로 (D-004)
- **localStorage 는 출처마다 따로 논다** — `file://` 과 `https://` 는 다른 저장소다.
  배포 방식을 바꾸면 편집분이 사라진다. B-11 전에 B-08 이 먼저다
- **Chrome 확장은 `file://` 을 못 연다** — 브라우저 자동 확인을 하려면 로컬 서버로
  띄워야 한다: `python3 -m http.server 8731`. 다만 그건 `file://` 검증이 아니다.
  최종 확인은 사람이 파일을 직접 열어서 한다
- **서비스워커·매니페스트는 `file://` 에서 안 붙는다** — 맥에서 더블클릭해 여는 동안은
  아무 일도 일어나지 않는 것이 정상이다. `https` 에 올라가야 판정된다
- **앱 편집은 그 기기에만 남는다** — 전 기기 반영은 원본을 고쳐 push 해야 한다 (D-014)
- **모바일 시뮬레이터는 터치감·소리·Wake Lock 을 판정하지 못한다** — 셋 다 실기기 전용
- **설치한 PWA 는 주소창도 새로고침 버튼도 없다** — 앱 전환기에서 다시 열어도 새로
  받아오지 않는다. "서버에 올렸으니 됐다"고 착각하기 딱 좋은 지점이다 (D-017)
- **GitHub Pages 는 `max-age=600` 을 보낸다** — 서비스워커가 네트워크 우선이어도
  브라우저 HTTP 캐시가 10분간 낡은 응답을 준다. `cache: 'reload'` 로 우회했다
- **매니페스트의 앱 이름은 이미 설치된 아이콘에 반영되지 않는다** — 지우고 다시 설치해야 한다
