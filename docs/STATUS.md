## 알려진 함정

- **외부 파일을 `fetch` 로 읽으면 `file://` 에서 통째로 죽는다** — CORS 로 막힌다.
  루틴 목록을 JSON 으로 분리하고 싶어질 때마다 이걸 떠올린다 (D-002)
- **`setInterval` 로 시간을 누적하면 백그라운드에서 밀린다** — 화면을 끄고 스트레칭하는
  게 정상 사용이므로 반드시 `Date.now()` 차이로 계산한다 (D-004)
- **localStorage 는 출처마다 따로 논다** — `file://` 과 `https://` 는 다른 저장소다.
  배포 방식을 바꾸는 순간 편집한 루틴이 사라진다. B-11 전에 B-08(내보내기)이 먼저다
- **모바일 시뮬레이터는 터치감·소리·Wake Lock 을 판정하지 못한다** — 셋 다 실기기 전용
