# 고도화 후보 (BACKLOG)

무엇을 **어떤 순서로** 할지의 목록. 지금 상태는 `STATUS.md`, 왜 그렇게 했는지는
`DECISIONS.md` 에 있다.

**표기**: `대기` / `진행중` / `완료 (YYYY-MM-DD)` / `보류(사유)`

**규칙**

- 번호(`B-xx`)는 다시 쓰지 않는다. 완료돼도 지우지 말고 상태만 바꾼다 —
  결정 장부와 커밋 메시지가 이 번호를 참조한다
- **새 작업이 생기면 먼저 여기 등록하고 시작한다.** 등록 없이 한 작업이 쌓이면
  이 문서는 계획이 아니라 유물이 된다
- 단계를 넘어 앞당기고 싶으면, 그 이유를 결정 장부에 적고 옮긴다

## 1단계 · 일단 돌아가게 — **지금 여기**

**B-01 이 막혀 있어도 B-02~B-04 는 자리표시자 목록으로 진행할 수 있다.**

| ID | 상태 | 할 일 |
|---|---|---|
| **B-01** | 대기 | **실제 루틴 항목 목록 받기** — 모닝/이브닝 각각 무엇을 몇 개, 시간 지정할 항목은 어느 것. 이게 없으면 자리표시자로 만들고 나중에 채운다 |
| **B-02** | 대기 | 본체 뼈대 — 시작 화면 → 항목 화면 → 요약 화면 흐름, 한 화면에 한 항목, 완료로 전진 |
| **B-03** | 대기 | 완료 피드백 — WebAudio "띵" + 진동 + 사라지는 전환, 소리 끄기 토글 (D-003) |
| **B-04** | 대기 | 늘어나는 타이머 — 시각 차이 계산, 항목별·전체 표시, 지정 시간 도달 알림 (D-004) |
