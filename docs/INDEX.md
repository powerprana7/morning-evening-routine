# 문서 지도 (INDEX)

문서마다 **답하는 질문이 하나씩** 있다. 같은 내용을 두 군데 적지 않기 위한 구분이다.
새 문서를 만들기 전에, 기존 문서 중 그 질문을 맡을 곳이 없는지 먼저 본다.

## 읽는 순서

1. `docs/STATUS.md` — **지금 어디까지 왔나** (세션 시작 시 이것만 읽으면 된다)
2. `CLAUDE.md` — **어떻게 일하나** (지켜야 할 규칙)
3. 필요할 때 아래에서 골라 본다

## 질문별

| 이 질문이 생기면 | 이 문서를 본다 | 갱신 시점 |
|---|---|---|
| 지금 뭐가 되고 뭐가 안 되나? 다음에 뭘 하지? | `docs/STATUS.md` | 동작이 바뀌는 커밋마다 |
| 어떻게 일해야 하나? | `CLAUDE.md` | 일하는 방식이 바뀔 때 |
| 왜 이렇게 만들었나? | `docs/DECISIONS.md` (D-001~) | 핵심 규칙·구조를 바꿀 때 |
| 다음에 할 일 목록은? | `docs/BACKLOG.md` (B-01~) | 작업을 시작·완료할 때 |
| <이 프로젝트 고유의 질문> | <문서> | <시점> |
